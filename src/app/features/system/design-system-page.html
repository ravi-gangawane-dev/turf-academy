Buttons — the complete reference

Every action button must use one of these shared recipes so it renders the same everywhere. Icon color is driven by the icon inside the button; destructive actions additionally carry the danger class.

Icon actions — app-button icon

34px square. Each family renders in its own solid color (see below); ghost buttons are exempt.

Color families

  • View / details — pi-eye, pi-user
  • Edit — pi-pencil, pi-user-edit
  • Confirm / pay / send — pi-wallet, pi-send, pi-whatsapp, pi-check, pi-check-circle, pi-user-plus
  • Destructive — pi-trash, pi-times, pi-user-minus, pi-power-off, pi-replay, pi-folder, or class danger
  • Documents / exports — pi-print, pi-file, pi-file-pdf, pi-download, pi-id-card
  • Copy / history / sync — pi-copy, pi-history, pi-sync, pi-undo, pi-arrow-right-arrow-left
  • Neutral — everything else

Complete variant & size matrix

Default height 42px (app-button), compact 34px (app-button small), tiny pill 30px (app-button chip) and square icon (app-button icon).

Filter chips & ghost icons

Chips (app-button chip) for removable filters/tags; ghost (app-button icon ghost) for dialog/toast closes and passive toggles.

Toggles, segmented controls & passive states

Period pickers, tabs and segments use app-button small secondary with active for the selected option. Pagination arrows use icon buttons.

Tooltip pattern (academy events)

Icon button plus hidden .action-tooltip span; shown on hover/focus.
